Learn Microsoft Excel Step by Step

A practical beginner-friendly guide to Microsoft Excel. Learn how spreadsheets work, practise useful formulas and build skills for school, office work and data analysis.

What is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to organise information, calculate values, analyse data and create charts. A workbook contains worksheets, and each worksheet is made of rows, columns and cells.

1. Understand cells, rows and columns

Columns run vertically and use letters such as A, B and C. Rows run horizontally and use numbers such as 1, 2 and 3. A cell is where a row and column meet. For example, A1 means column A, row 1.

2. Enter and format information

Click a cell, type a value and press Enter. You can enter text, numbers, dates and formulas. Use number formats, bold text, borders and column widths to make a worksheet easier to read.

3. Start with simple formulas

Excel formulas begin with an equals sign. If cell A1 contains 10 and B1 contains 5, these formulas calculate common operations:

=A1+B1   adds values
=A1-B1   subtracts values
=A1*B1   multiplies values
=A1/B1   divides values

4. Learn useful Excel functions

Functions are built-in formulas that make calculations easier. SUM adds values, AVERAGE finds the mean, MIN returns the smallest value, MAX returns the largest value and COUNT counts cells containing numbers.

=SUM(B2:B10)

This example adds all the numbers from B2 through B10.

5. Organise data with tables and filters

Excel tables help keep related information together. They provide column headings, consistent formatting and filter controls. Sorting arranges information, while filtering temporarily shows only rows that match a condition.

6. Create charts and analyse data

Charts turn spreadsheet values into visuals such as column, bar, line and pie charts. PivotTables help summarise larger lists by categories, totals or counts.

7. Practise with a real project

Create a weekly money tracker with columns for date, money received and money spent. Add a total using SUM, then make a chart to compare the amounts. Practising with a real task helps you remember each skill.

Suggested Excel learning path

  1. Workbook, worksheet, rows, columns and cells
  2. Entering data and formatting cells
  3. Basic arithmetic formulas
  4. SUM, AVERAGE, MIN, MAX and COUNT
  5. IF, sorting and filtering
  6. Tables, charts and PivotTables
  7. Lookup functions and practical projects
